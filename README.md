# Udbhav Sanagari — Developer Dossier 📁

An interactive, forensic editorial developer portfolio showcasing production systems, low-latency architecture, local LLM agent orchestration, and systems engineering.

Inspired by the design language of [Paper Trail](https://paper-trail-lilac.vercel.app/).

---

## ⚡ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Hosting**: Optimized for [Vercel](https://vercel.com/) (zero-config SPA)

---

## 🏛️ Signature Views

1. **Dossier (Explore)**: Filterable, searchable portfolio of verified systems across AI Agents, Rust Desktop, Systems & Low-Latency, and Computer Vision.
2. **Story (The Journey)**: Chronological chapters tracing the engineering evolution from foundational C++ systems to autonomous local agents and sub-2ms hardware-accelerated streaming.
3. **Insights (Telemetry)**: Visual engineering analytics, language distribution breakdown, architectural domains, and benchmark metrics.
4. **Connect (Matrix)**: Interactive graph engine computing deterministic relationship strength and architectural overlaps between systems.
5. **Resume Dossier**: Single-click ATS-verified resume viewer and direct PDF download.

## 🚀 Local Development

```bash
# Clone repository
git clone https://github.com/Udbhav7002/portfolio_website.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```

---

## 🌐 Deploying to Vercel

This repository includes a pre-configured `vercel.json` for seamless zero-config deployment.

1. Push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/Udbhav7002/portfolio_website.git
   git branch -M main
   git push -u origin main
   ```
2. Go to [Vercel](https://vercel.com/new), select your `portfolio_website` repository, and click **Deploy**.
